SC26 openQSE Demonstration

Overview

The SC26 openQSE Demonstration presents the open Quantum Software Ecosystem (openQSE), including the interfaces that connect quantum resources to HPC systems and the workflow tools and libraries built on top of them. It shows how these software layers fit together to support real quantum-HPC applications.

How we count

Commits reachable from each configured main branch since July 1, 2026, using the commit date. DEFw uses its master branch. Merge commits are included. Automated commits are included in the totals. Charts show eight weeks of activity in seven-day groups. The last-seven-days count includes today (UTC).

People are identified from commit authors and co-author credits; bot accounts are omitted from the people list. A shared commit can credit more than one person. Unlinked identities may appear separately until reconciled. Repository totals can overlap when histories share commits. Institution acknowledgements are curated from our community credits, rather than inferred from email addresses or tied to this date window.

DOE Demo Resources

Resource Description
QFw Slurm Cluster Source code and documentation for a containerized Slurm environment for running QFw quantum and hybrid workflows.
Build and start the cluster Configure, build, and launch the Docker-based cluster, then verify its Slurm nodes. Includes instructions for stopping and recreating the environment.
Pasqal EMU_FREE site service Configure Pasqal Cloud's free emulator as a shared site device and run Pulser jobs through QFw. The operator supplies the cloud credentials and controls user access.
Pulser jobs on Pasqal Run Pulser examples on Pasqal's EMU_FREE emulator or FRESNEL QPU using your own cloud account and a job-owned quantum resource manager. Supports QRMI and native QDMI access.
Prefect SQD closed loop Set up and run a Prefect workflow that optimizes quantum circuit parameters, samples circuits, recovers configurations with sample-based quantum diagonalization (SQD), and runs a classical solver through Slurm MPI jobs.
Backline QEC integration Configure the Backline quantum resource manager to reserve a controller, QEC decoder coprocessor, and transport. Applications use the assigned resources to execute PennyLane/Catalyst programs directly.
Run QFw against Amazon Braket Set up an Amazon Braket account, configure the service's AWS identity and device file, perform free checks, and run the first circuits through QFw.
Site services with the AWS QPM Deploy long-running site services, including the AWS quantum resource manager (QPM), with aws-sv1 and aws-cepheus exposed as site devices.
Amazon Braket QDMI library QDMI device library for Amazon Braket, maintained by munich-quantum-software.
Helium chemistry workflow He4 fragment molecular orbital (FMO) calculations and the paired unitary coupled cluster doubles (pUCCD) variational quantum eigensolver (VQE). The Braket stages are a pending patch.
DOE demo scenario diagram Scenario diagram in the Workflow Diagrams folder of openQSE Confluence. Sign-in is required.
