Overview

The SC26 openQSE Demonstration presents the open Quantum Software Ecosystem (openQSE), including the interfaces that connect quantum resources to HPC systems and the workflow tools and libraries built on top of them. It shows how these software layers fit together to support real quantum-HPC applications.

Resources

Resource Description
QFw Slurm Cluster Source code and documentation for a containerized Slurm environment for running QFw quantum and hybrid workflows.
Build and start the cluster Configure, build, and launch the Docker-based cluster, then verify its Slurm nodes. Includes instructions for stopping and recreating the environment.
Pasqal EMU_FREE site service Configure Pasqal Cloud's free emulator as a shared site device and run Pulser jobs through QFw. The operator supplies the cloud credentials and controls user access.
Pulser jobs on Pasqal Run Pulser examples on Pasqal's EMU_FREE emulator or FRESNEL QPU using your own cloud account and a job-owned quantum resource manager. Supports QRMI and native QDMI access.
Prefect SQD closed loop Set up and run a Prefect workflow that optimizes quantum circuit parameters, samples circuits, recovers configurations with sample-based quantum diagonalization (SQD), and runs a classical solver through Slurm MPI jobs.
Backline QEC integration Configure the Backline quantum resource manager to reserve a controller, QEC decoder coprocessor, and transport. Applications use the assigned resources to execute PennyLane/Catalyst programs directly.
