# QCE26 OpenQSE BoF Slide Fodder

## Discussion Prompts

- What requirements are missing from the current openQSE roadmap or working group plans?
- Where do system architecture, QRI, runtime, compiler, and control electronics interfaces need clearer boundaries?
- What quantum-HPC workflows are hardest to express, schedule, compile, or execute portably today?
- Where would common specifications or reference implementations reduce fragmentation across runtimes, resource management, orchestration, execution, observability, and application workflows?
- What testing and validation practices are needed for NISQ and fault-tolerant system readiness?
- What governance model would make shared specifications durable and credible?
- Which existing community efforts should openQSE align with?
- What would make it easier for attendees and their organizations to participate in openQSE working groups?
